# 제1강 단원평가

<div class="note-key"><ul><li><b>빈칸 채우기</b>: 교본 원문 문장의 중요한 항목이 빈칸입니다. 직접 입력하세요. 띄어쓰기·쉼표는 채점에 영향을 주지 않습니다. 입력 후 Enter를 누르면 다음 빈칸으로 넘어갑니다.</li><li><b>O/X</b>: 교본 원문 그대로면 O, 한 곳이라도 바뀌었으면 X입니다.</li><li><b>5지선다</b>: 근거는 모두 2026 교본 원문입니다. 오답 보기와 X 문장은 원문을 바꾼 것입니다.</li><li>채점하면 문항마다 교본 원문과 쪽 번호가 나오고, 쪽 번호를 누르면 e-book 원본 지면이 열립니다.</li><li>문제은행의 상당수는 교본 문장을 그대로 가져와 자동으로 만든 문항입니다. 교본 글자 인식 과정에서 띄어쓰기·글자가 틀린 곳이 있을 수 있으니, 이상한 문장은 쪽 번호를 눌러 원본 지면으로 확인하세요.</li></ul></div>
