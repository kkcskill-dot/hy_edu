# Part 1. 일반직 인사규정

## 제1장 총칙 <a class="src" href="reader.html?doc=unit04&p=15">p.15</a>

- **제1조(목적)** 의료원의 창립 이념에 따라 교육 및 의료업무의 원활한 수행을 위하여 직원에게 적용할 인사 행정의 근본기준을 확립하여 공정하고 능률적인 운영을 기함
- **제2조(직원범위)** 일반직은 **교수직, 수련직을 제외한 정규직원**
- **제3조(적용범위)** 다른 법령 또는 타 규정에 특별히 정한 경우를 제외하고는 이 규정에 의함

**제4조(용어)** <a class="src" href="reader.html?doc=unit04&p=3">p.3</a>

| 용어 | 정의 | 예(강의 Point) <a class="src" href="reader.html?doc=unit04&p=4">p.4</a> |
| :--- | :--- | :--- |
| 직위 | 1인의 직원에게 부여할 수 있는 직무와 책임 | 국장, 팀장(부장), 파트장(차장), 직원 등 |
| 직군 | 본질적인 성격이 유사한 직무들의 묶음 | 교수직, 수련직, 일반직, 기타 등 |
| 직종 | 직무수행능력이 가깝고 그 특수성과 전문성에 따라 구분되는 직무의 계열 | 의료기술(능)직, 일반기술(능)직, 사무직, 업무지원직, 기타 등 |
| 직무 | 각 직위에 배정된 업무로써, 해당 직원이 실제 담당하고 있는 일 | 간호사, 방사선사, 임상병리사, 사무원, 기능원 등 |
| **승진** | 직급이 하위급에서 상위급으로 오르는 것 | 예: 5급 8호봉 → 4급 2호봉 / 자격을 갖추고 전형을 통과해야 대상 |
| **승급** | 직원 기본급의 호봉이 하위호봉에서 상위호봉으로 오르는 것 | 예: 5급 12호봉 → 5급 13호봉 / 제외조건에 해당하지 않으면 대상 |
| 보직 | 직원에 대하여 특정직위를 부여하고 그 직무를 수행케 함 | |
| 복직 | 휴직 또는 정직중에 있는 직원을 직무에 복귀시키는 것 | |
| **전보** | 직제규정 및 직무분장 규정에 의거 담당업무의 변동이나 근무부서의 이동 | |
| **전직** | 채용시 기능과 적성에 따라 부여받은 직종이 다른 직종으로 변경됨 | |

**제5조(직급구분)** 직원은 **1급, 2급, 3급, 4급, 5급, 6급, 7급, 8급**으로 구분 (※ 용인: M1급 ~ M8급) <a class="src" href="reader.html?doc=unit04&p=5">p.5</a>

| 직급별 호칭 <a class="src" href="reader.html?doc=unit04&p=5">p.5</a> | |
| :--- | :--- |
| 1급 보직자 | 국장 |
| 2급 보직자 | 부장 |
| 3급 보직자 | 차장 |
| 3급 직원 | **과장** |
| 4급 직원 | **선임** |
| 5급 ~ 8급 직원 | 직원 (업무지원직 5~6급: 주임) |

- **제6조(임용분류)** 직종의 난이성, 해당 직무가 필요로 하는 자격, 해당직위의 책임의 정도 등을 기준으로 임용 분류 — 임용분류 기준표는 별표(1) <a class="src" href="reader.html?doc=unit04&p=15">p.15</a>
- **제7조(인사권자)** 직원의 임면, 승진, 승급 등에 관한 모든 인사권은 **의료원장(의무부총장)**이 행함 <a class="src" href="reader.html?doc=unit04&p=16">p.16</a>
  - 예외: 실장급, 처장급, 부처장급, 국장급 및 팀장급(부장)의 임면은 **직제규정**이 정하는 바에 의함
  - 의료원장은 필요하다고 인정할 때 **인사권의 일부를 위임**할 수 있음
- **제8조(임면통지)** 별지서식 **발령통지서**에 의함
- **제9조(인사위원회 구성)** 인사권자의 자문에 응하기 위하여 인사위원회를 구성할 수 있음

## 제2장 채용 <a class="src" href="reader.html?doc=unit04&p=16">p.16</a>

- **제10조(채용원칙)** 소정의 자격을 가진 자 중에서 **고시 및 전형**에 의하여 채용함을 원칙 / 신규채용 요건은 임용분류 기준표에 의하여 의료원장이 정함
- **제11조(채용시험 시기)** 고시에 의한 채용시험은 결원 인원에 대하여 시행, 시기는 의료원장이 정함
- **제12조(선발방법)** **서류심사, 면접시험 및 신체검사** (직종에 따라 인적성검사와 필기 및 실기시험 가능) / 필기시험 과목은 **교양과목 및 전공과목**
- **제13조(전형에 의한 채용)** 1. 직무의 특수성으로 고시채용이 불가한 경우 2. 국가 보훈 대상자 3. 삭제 4. 정년 또는 명예퇴직자 중 정책회의 심의를 거쳐 **계약직**으로 채용할 수 있는 자 (가. 의료원 성장 및 도약에 크게 기여 / 나. 고도의 숙련도와 전문적 지식으로 업무연속성 필요 / 다. 국가적 질병재난 또는 병원의 경영위기상황으로 긴급히 필요)
- **제14조(전형방법)** 서류심사, 면접시험, 신체검사 원칙 (채용직무에 따라 서류심사와 신체검사)
- **제15조(건강진단)** 본원의 신체검사 기준에 합격하여야 함

**제16조(결격사유)** — 채용할 수 없는 자 <a class="src" href="reader.html?doc=unit04&p=17">p.17</a>

1. 금치산자나 또는 한정치산자
2. 파산자로서 복권되지 아니한 자
3. 금고이상의 형을 받고 그 집행이 종료되거나 집행을 받지 아니하기로 확정된 후 **5년**을 경과하지 않은 자
4. 금고이상의 형을 받고 집행유예의 기간이 완료된 날로부터 **2년**을 경과하지 아니한 자
5. 법원의 판결에 의하여 자격이 상실 또는 정지된 자
6. 징계 면직을 받거나 부정, 근무태만 또는 기타 불미한 사유로 해직된 자
7. 금고이상의 형의 선고유예를 받고 그 선고 유예 기간중에 있는 자
8. 신체검사 불합격자
9. 의료원의 제 규정에 저촉되어 부적당하다고 인정되는 자
10. 「아동·청소년의 성보호에 관한 법률」 제56조에 따라 취업제한을 명령받은 의료인

| 용어 풀이 (강의) <a class="src" href="reader.html?doc=unit04&p=6">p.6</a> | |
| :--- | :--- |
| 금치산자 | 정신적 제약으로 사무처리 능력이 **지속적으로 결여**된 사람 (민법 제9조 성년후견개시의 심판 → 피성년후견인) |
| 한정치산자 | 정신적 제약으로 사무처리 능력이 **부족**한 사람 (민법 제12조 한정후견개시의 심판 → 피한정후견인) |
| 파산자 | 가지고 있는 재산으로 모든 빚을 갚을 수 없는 상태(파산)가 되어, 법원에서 공식적으로 파산 선고를 받은 사람 |
| 복권 | 파산 선고로 인해 제한받았던 공적·사적 자격과 권리를 되찾아 파산선고 전의 상태로 회복되는 것 |

- **제17조(직원의 인사청탁 금지)** 인사행정의 공정성을 위하여 인사 청탁은 금함 <a class="src" href="reader.html?doc=unit04&p=17">p.17</a>
- **제18조(구비서류)** 이력서, 근로계약서, 학력·자격 및 면허 증명서류, 종교상황확인서, 주민등록초본(군경력 기재), 사진, 인사기록표 및 인사기록카드, 건강진단서, 기타 <a class="src" href="reader.html?doc=unit04&p=17">p.17</a>
- **제19조(채용자 임용기준)** 별표(1)·별표(2) / 초임 호봉은 별표(2) (필요시 별도 조정) / 경력직은 경력환산기준에 따라 조정 (전문직은 별도) <a class="src" href="reader.html?doc=unit04&p=17">p.17</a>
- **제20조(직종부여 및 변경)** 기능과 적성에 따라 직종 부여, 의료원장이 필요하다고 인정하면 변경(**전직**) — 전직은 전직 예정직종 및 직위에 **결원이 있을 시에 한하며**, 고시 또는 전형으로 적성과 능력이 인정되어야 함 <a class="src" href="reader.html?doc=unit04&p=17">p.17</a>

## 제3장 보직 <a class="src" href="reader.html?doc=unit04&p=18">p.18</a>

- **제21조(보직원칙)** 직제규정 및 직무분장 규정에 의함 / 능력과 특기에 따라 **적재적소** 배치 / **기회균등** 원칙, 직책별로 보직의 균등 보장
- **제22조(보직기간)** 동일 소속 및 동일 직책에서 특별한 사유가 없는 한 **6개월 이상** 보직
- **제23조(보직변경)** 능력향상과 근무의욕 고취를 위하여 **동일 직급 내에서 순환근무**토록 보직 변경 가능
- **제24조(서리, 겸직, 직무대리)**
  1. 국장급·팀장급(부장) 직위에 보직하려는 당사자가 해당업무 수행능력이 있다고 인정될 때까지 → **서리**
  2. 국장급·팀장급(부장) 직위자가 장기간 유고시 → 동급직위자 **겸직** 또는 차하위자 **직무대행**
  3. 파트장급(차장) 직위에 차하위 직급자를 보직하려는 경우 승진될 때까지 → **직무대리**
- **제25조(직위해제 조치)** 직위를 부여하지 아니하는 자: 1. 직무수행능력이 현저히 부족하거나 근무성적이 불량한 자 2. 소속 부하직원에 대한 지휘 및 감독능력이 부족한 자 3. 품위를 손상하여 다른 직원에게 현저하게 나쁜 영향을 끼친 자 4. 정당한 명령, 지시를 이행하지 않는 자 5. 징계의결 요구 및 회부중인 자로서 직위해제가 필요한 자 6. 파렴치한 행위를 한 자 — **단, 그 기간은 6개월 이내**
  - 제1호~제2호로 직위해제된 자: **3개월 이내** 대기 명령 가능 → 교육 훈련 또는 별도의 과제 부여, 향상 의지가 없으면 **인사위원회 또는 징계위원회의 동의**를 얻어 면직 가능
- **제26조(수습)** 신규채용 직원은 발령일로부터 **3개월**간 수습 (본원에서 동일직무에 **6개월 이상** 계속 근로한 비정규직은 수습 미적용) / **수습기간은 근속년수에 산입** <개정 2023.11.30.> / 수습기간중 무자격자·채용기준 결격자·부적격자는 **예고 없이 해고**

## 제4장 승진·승급 <a class="src" href="reader.html?doc=unit04&p=19">p.19</a>

- **제27조(승진구분)** **고시승진, 연공승진, 인사평가에 따른 승진**
- **제28조(승진시험의 종류)** **고시와 전형**
- **제29조(승진인원 책정)** 충원과 인재개발을 고려하여 별도로 책정
- **제30조(고시 및 전형 응시자격)** 별표(3)에 적합한 자 / 현직급 재직중 특별승급된 기간과 채용시 초임 호봉에 가산 받은 기간은 최소 근무년수에 산입하되 **기준년한의 50%를 초과할 수 없음** / 단, **군경력으로 가산받은 호봉은 승진기준 호봉 및 년한에 포함하지 않음**
- **제31조(고시승진 시기)** **매회계년도 말** 시행 원칙 (의료원장이 시기 조정 가능)
- **제32조** 고시승진 및 인사평가에 따른 승진의 전형기준 및 방법은 의료원장이 정함
- **제33조(연공승진)** 근무성적이 양호한 경우 **부서장의 내신**으로 연공에 의하여 승진 / **2급 이상으로의 연공승진은 단위기관장의 내신 → 특별인사위원회 심의**
  - 승진상한 직급: 사무직, 기술·기능직 **2급** / 업무지원직(기능원) 7급 채용자 **4급**, 8급 채용자 **5급**
- **제34조(최소근무년수)** 별표(3)의 직급별 승진 최소근무년수 원칙 (형평 고려하여 근속년수가 최소근무년수 합계를 상회하면 인정 가능)
- **제35조(특별승진)** 의료원장이 필요하다고 인정하는 자를 **정원 범위내**에서: 1. 유익한 발명 또는 연구 고안 결과가 지극히 양호 2. **순직자 또는 공상으로 인하여 퇴직하는 자** 3. 장기근속자로서 별도 기준에 해당

**제36조(승진결격 사유)** — 승진기준일(정기승급일) 현재 해당하면 승진심사대상에서 제외 (승진심사 이후 발생한 사유라도 당해연도 승진대상에서 제외) <a class="src" href="reader.html?doc=unit04&p=20">p.20</a><a class="src" href="reader.html?doc=unit04&p=7">p.7</a>

1. 최근 1년간 **감봉 1개월 이상**의 징계처분을 받은 자 (단, 동 기간중 **공로상, 특별상**의 표창을 받은 자는 예외)
2. 최근 1년간 근태불량으로 **2회 이상 경고**를 받은 자
3. 최근 1년간 휴직 또는 질병으로 **30일 이상 결근**한 자 — 강의: 휴직(청원, 질병, 육아휴직연장) 포함, **4대 중증질환(암·심장·뇌혈관·희귀난치질환)으로 인한 질병 휴직도 제외사유에 포함**
4. 최근 1년간 **안식휴가를 30일 이상** 사용한 자
5. 고시 또는 전형결과가 일정수준을 넘지 못한 자
6. 기타 의료원장이 부적당하다고 인정하는 자

- **제37조(승진자 기본급)** 승진시의 호봉은 **현재 금액과 동일한 금액의 차상위 호봉** 부여 <a class="src" href="reader.html?doc=unit04&p=8">p.8</a>
  - 강의 예시(가정): 5급 7호 2,200,000원 · 5급 8호 2,250,000원 / 4급 1호 2,150,000원 · 4급 2호 2,300,000원 → **5급 7호에서 승진해도, 5급 8호에서 승진해도 4급 2호**
- **제38조(승급구분)** **정기승급과 특별승급**
- **제39조(정기승급)** 채용일 또는 전 승급일로부터 매1년이 경과할 때마다 **매년 3월 1일과 9월 1일** 실시 / 개개인의 정기승급 일자는 **승진 또는 전직시에 변경하지 않음** / 군복무기간 호봉반영 후 잔여월수는 채용일에 합산 <a class="src" href="reader.html?doc=unit04&p=20">p.20</a>
- **제40조(특별승급)** 인사평가 성적이 탁월한 자: 인원수는 각 직급별 정원의 **5% 이내**, 동일 직급에서 **4회 이내** / 그 밖에: 공로상 또는 특별상을 받은 자, 정부·공공기관 공로상으로 의료원 명예를 크게 선양한 자, 유익한 발명·연구 고안 결과가 양호한 자, 기타 <a class="src" href="reader.html?doc=unit04&p=20">p.20</a>

**제41조(정기승급 제외)** <a class="src" href="reader.html?doc=unit04&p=20">p.20</a><a class="src" href="reader.html?doc=unit04&p=8">p.8</a>

  - 단, 예외: 의료원장이 인정한 특명 휴직자·파견자 / 제47조 1항 2호, 5호 휴직이 **4대 중증질환**(산정특례 적용)으로 인한 경우(**동일 상병 1회 한정**) / 6호(법정기간 1년) / 9호(최초 90일)

- 정기승급일 현재 최근 1년간 인사평가성적 또는 근태상황이 **극히 불량**한 자

- **제50조(휴직자의 보수)** 무급 원칙. 단, **4호·5호: 3개월은 통상임금 전액, 그 후 6개월은 통상임금의 60%** (난임은 미적용) <a class="src" href="reader.html?doc=unit04&p=22">p.22</a>

**제52조(직권면직)** <a class="src" href="reader.html?doc=unit04&p=22">p.22</a>

  - 대학 및 병원 **단위기관장 직속** 포상·징계위원회 심의 사항: 1. 근속상 및 순직 또는 정년퇴직에 대한 포상을 **제외한** 포상 2. 징계대상자가 일반직 **파트장급 이하 또는 계약직**인 징계사항

- **제4조(임무)** 포상 및 징계에 관한 사항을 심의 의결하여 **의료원장에게 건의**

  - **단위기관 위원회는 위원장 1인과 위원 6인 이상** <a class="src" href="reader.html?doc=unit04&p=28">p.28</a>

**제12조(포상구분과 대상)** — 포상은 **공로상, 모범상, 근속상, 특별상**

| 포상 | 대상 |
| :--- | :--- |
| 공로상 | 기술상 혹은 업무상 유익한 발명 또는 연구고안을 하여 그 결과가 현저한 공적이 있거나 재해의 미연방지 또는 비상사태 하에서 공로가 있는 **개인 또는 부서** |

**제18조(용어)**

| 징계대상자 | 징계가 확정되기 전까지의 대상자 |

**제19조(징계의 원칙)**

1. 동일한 행위에 대한 징계처분의 종류와 정도가 달라서는 안 된다.
2. 여하한 징계사유에도 불구하고 **동일한 비행에 대하여 두번 징계할 수 없다.**
3. 징계기준을 판단하기 어려운 행위는 **징계대상자에게 유리한 기준**을 적용
4. 관련자가 2인 이상으로 책임의 한계가 명확치 않을 때는 **동등히 처벌**
5. 징계처분 시 본인에게 **변명 또는 소명의 기회**를 주어야 한다.

**제20조(징계의 사유)** — 다음 각 호 및 별표(1)의 비위 유형에 해당하면 징계 처분 <a class="src" href="reader.html?doc=unit04&p=30">p.30</a><a class="src" href="reader.html?doc=unit04&p=31">p.31</a>
1. 법령 및 제규정에 의한 준수사항과 서약서에 위배된 행위 2. 의료원의 명예와 위신을 손상시키는 행위 3. 의료원의 경영 또는 재산에 손해를 끼치는 행위 4. 직장 내 풍기질서 또는 복무질서를 문란시키는 행위 5. 직무유기 또는 근무태만 행위
