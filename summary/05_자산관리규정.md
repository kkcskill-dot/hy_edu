## 제1장 총칙

**강의 목차**: 제1장 총칙(자산의 이해, 관리업무, 관리담당자) · 제2장 취득(자산의 청구, 취득절차) · 제3장 관리(자산번호, 이동, 실사, 반납, 처분, 손망실) <a class="src" href="reader.html?doc=unit05&p=2">p.2</a>

- **제1조(목적)** 의료원 내의 자산관리를 규정하여 자산의 **취득, 사용, 유지보존, 관리전환, 처분** 등 재산상태의 정확한 파악과 효과적인 운영관리에 관한 사항을 규정 <a class="src" href="reader.html?doc=unit05&p=14">p.14</a>
- **제2조(정의)** 자산 = 연세대학교 정관 제6조에 준하여 의료원의 사업을 수행할 목적으로 계속적으로 소유 또는 점유하는 **기본재산과 보통재산**
  - **기본재산**: 원본소비를 목적으로 하지 않는 재산으로서 교육용 및 수익용의 **토지, 건물, 건물부속설비, 구축물** 등 — **취득과 동시에 학교법인에 이관**
  - **보통재산**: 기본재산 이외의 재산

**제3조(자산의 구분)** — 자산은 **유형자산, 부외자산, 재고자산** <개정 2007.3.1: 부외자산 추가 / 2020.11.1: 관리자산 삭제> <a class="src" href="reader.html?doc=unit05&p=14">p.14</a><a class="src" href="reader.html?doc=unit05&p=4">p.4</a>

| 구분 | 요건 | 회계·관리 | 자산번호 |
| :--- | :--- | :--- | :--- |
| **유형자산** | 내용연수 **2년 이상** + 취득가액 개당 **1,000,000원 이상** (모두 충족) | 재무상태표 **'자산'의 부에 계상** | **1~7**로 시작 |
| **부외자산** | 내용연수 **2년 이상** + 개당 **1,000,000원 미만 500,000원 이상** (모두 충족) — 단, 사용부서의 관리가 필요한 품목은 **50만원 미만이라도** 자산으로 관리 | 사용부서에서 **자체 관리**, 장부상 **'비용'**으로 처리 (예: 연구용 컴퓨터, 시험용기기) | **9**로 시작 |
| **재고자산** | 의약품, 일반 및 의료소모품, 직물 등 **소모성비품**인 자산 | | |

**제4조(자산관리 업무) · 제5조(자산관리 담당자)** <a class="src" href="reader.html?doc=unit05&p=15">p.15</a><a class="src" href="reader.html?doc=unit05&p=4">p.4</a>

| 부서 | 업무 |
| :--- | :--- |
| **주관부서**(구매팀) | 효율적인 수급계획·유지·전반적 운영 총괄 — 자산의 전산 관리 / 취득, 반납, 폐기, 매각, 이동 관리 / 부동산 등기, 매각 / **유형자산실사 주관** / **손망실된 유형자산의 처리** / 기타 |
| **사용부서** | 자산을 직접 사용·운영 — 주관부서 관리대장과 보유자산의 **일치 유지**(수시 실사, 차이 시 주관부서 확인) / 보관 및 유지보전 / 관리·보관·보존·기록유지 |
| **기술부서** | 자산의 **유지보수 및 계속사용 여부**에 대한 기술적인 의견 제시 |
| **자산관리 담당자** | 각 부서(**검사실 포함**)에 **정·부책임자**, 소관자산의 보존 및 사용 책임 |

- 자산의 관리책임(강의): **원칙적 책임 = 각 부서 자산관리담당자 / 최종 책임 = 부서장** / 특수목적 업무 수행(연구소 등) 목적 자산 = **주 연구자** <a class="src" href="reader.html?doc=unit05&p=4">p.4</a>
- **제6조(적용범위)** 의료원 **전 산하 회계단위**에 적용

## 제2장 취득

- **제7조(자산의 취득)** 구입, 제작, 증여, 교환, 대체, 개조, 기타방법 <a class="src" href="reader.html?doc=unit05&p=15">p.15</a>
- **제8조(취득의 구분)** **일반취득 = 구입, 제작** / **특별취득 = 국내외 증여, 교환, 대체, 개조 및 기타방법**

**제9조(취득가액)** <a class="src" href="reader.html?doc=unit05&p=15">p.15</a><a class="src" href="reader.html?doc=unit05&p=5">p.5</a>

| 취득 방법 | 취득가액 |
| :--- | :--- |
| 구입 | 구입가격 + **부대비** (설치비용, 각종세금, 운송비용, 창고료 등) |
| 공사 또는 제작 | 원가 + 부대비 |
| 무상취득 또는 재활용 | 정당한 **평가액** |
| 교환 | 양도자산의 **장부가액**에 교환 자금 및 부대비를 가감한 금액 |

- 재무상태표 가액은 취득가액 (자산평가법에 의하여 재평가한 경우에는 그 가액) <a class="src" href="reader.html?doc=unit05&p=16">p.16</a>
- **제10조(취득시기)** 구입, 증여, 제작물 등은 **검수한 날** / 기본재산의 신설, 확장 등은 **자산확정일**

**제11조(자산의 청구 및 취득절차)**: ① 취득승인 → ② 검수 → ③ 기장 <a class="src" href="reader.html?doc=unit05&p=16">p.16</a><a class="src" href="reader.html?doc=unit05&p=5">p.5</a>

| 단계 | 내용 |
| :--- | :--- |
| 취득승인 | **일반취득**: 사용부서가 **구매요청(구매청구서)**을 주관부서에 신청 / **특별취득**: 사용부서가 **취득일로부터 1개월 이내** '기부채납 및 자산등록신청서' 또는 '자산등록신청서' 제출 / **재고자산**: '재고예약서' 제출 → 주관부서가 위임전결 규정에 따라 취득 여부 결정·승인 |
| 검수 | 주관부서가 계약 체결·납품지시 → 검수부서의 검수 (기술적인 검수가 필요하면 **사용부서장 및 기술부서장**의 검수) / **시설공사는 준공검사조서로 검수에 갈음** |
| 기장 | 주관부서가 취득 품목을 지체없이 기록·보관 / 소유권 확보된 권리증 사본 비치 / 존속·유효기간이 있는 권리는 기간 도래 시 지체없이 연장·갱신 |

- 강의 실무 팁 <a class="src" href="reader.html?doc=unit05&p=6">p.6</a>
  - '최적의 구매요청 타이밍'은 최고의 비용절감 효과 — 컨설팅/용역 등 · 의료장비 유지보수 · 공사/가구는 **3개월 이전** 구매요청
  - '정확한 검수'는 세브란스를 건강하게 — 물품 청구·수리 청구 시 요청 물품·수량·파손 여부, 정품 여부 등 확인
  - 효율적인 자산 관리의 시작 올바른 자산 등록: **연구비 등 취득 단가 50만원 이상 물품은 '자산 등록'**이 필요 (그룹웨어 경로: wERP - 재무회계 - 자산관리 - 자산등록/자산이동신청/자산반납신청)

## 제3장 관리

**제12조(자산의 번호)** 기관별, 자산계정별, 품목별로 분류하고 **일련자산번호 표찰**을 부착 — 자산클래스별 **7자리** 숫자 부여 <a class="src" href="reader.html?doc=unit05&p=16">p.16</a><a class="src" href="reader.html?doc=unit05&p=6">p.6</a>

| 자산클래스 | 1 | 2 | 3 | 4 | 5 | 6 | 7 | 9 |
| :--- | :--- | :--- | :--- | :--- | :--- | :--- | :--- | :--- |
| 분류 | 토지 | 건물 | 기계장치(기구) | 의료장비 | 공기구비품 | 건설 중인 자산 | 도서, 예술품 | **부외자산** |

**제13조(자산의 변동)** <개정 2026.8.21.> — 인계 및 인수부서가 상호 합의하여 이동 <a class="src" href="reader.html?doc=unit05&p=16">p.16</a><a class="src" href="reader.html?doc=unit05&p=7">p.7</a>

| 구분 | 절차 |
| :--- | :--- |
| **단위기관 내** | 인계 및 인수 **부서장**의 결재 후 **주관부서의 승인** |
| **단위기관 간** | 인계 및 인수 **단위기관장**의 결재 후 **주관부서의 승인** |
| 단위기관 간 예외 (→ 부서장 결재 + 주관부서 승인) | 1. 취득가액 **500만원 미만**인 기계기구, 의료장비, 공기구비품 2. 종전 규정(2020.11.1. 개정 전 제3조)에 따라 기 생성되어 **관리자산**으로 분류된 자산 전체 3. **부외자산 전체** |
| 강의 주의 | **대학 → 병원 이동 불가** |

- **제14조(자산의 수리)** **등록된 자산에 한하여** 고장수리 요청 사항을 작성, 직무분장규정이 정한 담당부서에 의뢰 <a class="src" href="reader.html?doc=unit05&p=17">p.17</a>

**제16조(감가상각)** — 유형자산에 생기는 자본가치의 소모(물리적, 기능적 감가)를 결산기마다 그 자산의 가격을 감해가는 회계상의 절차 <a class="src" href="reader.html?doc=unit05&p=17">p.17</a><a class="src" href="reader.html?doc=unit05&p=8">p.8</a>

| 항목 | 내용 |
| :--- | :--- |
| 근거법 | **법인세법** |
| 실시시기 | **회계연도말** 기준 |
| 방법 | **정액법**(의료원): 내용연수 동안 균등상각 ↔ 정률법: 내용연수 동안 일정률에 따라 상각 — 건물, 건물부속설비, 구축물, 기타 유형자산 및 무형자산 모두 정액법 (2013.3.1. 개정: 정률법 → 정액법 <a class="src" href="reader.html?doc=unit05&p=20">p.20</a>) |
| 기준 내용연수(강의) | 건물(철골, 철근) **40년** · 그 외 유형자산 **5년** · 중입자 치료기 **20년** |
| 변경 | 장부가액 또는 내용연수 변경 시 변경 후 기준으로 상각 |

**제17조(자산의 실사) · 제18조(간접실사 방법)** — 장부와 실물이 일치하는지 확인하기 위해 자산의 과부족, 상태 등 현황 조사 <a class="src" href="reader.html?doc=unit05&p=17">p.17</a><a class="src" href="reader.html?doc=unit05&p=8">p.8</a>

- 실사방법: **주관부서의 직접실사** / 각 단위기관에서 부서별로 실사하여 보고하는 **간접실사**
- 간접실사 흐름: 사용부서 '**재물조사 결과보고서**' 작성 → 부서장 결재 → 총괄부서(각 행정지원부서) 집계 → **단위기관장 결재** → 주관부서 제출 → 주관부서는 손망실 건·부실 보고서 재확인, 전말조서 작성하여 **의료원장에게 보고**
- **부외자산은 사용부서에서 직접 관리 → 주관부서의 실사는 제외**

**제19조(자산의 반납)** <a class="src" href="reader.html?doc=unit05&p=18">p.18</a><a class="src" href="reader.html?doc=unit05&p=9">p.9</a>

- 흐름: 사용부서 반납신청('**자산반납신청서**', 부서장 결재) → 기술부서 기술검토 → 사용부서 수거요청 → 구매팀 반납 승인 → 수거/처분
- 반납된 자산은 **기술부서의 검토의견**을 받아 처리 — 단, **부외자산은 기술검토의견 생략 가능**
- 주관부서는 취득일자, 잔존가액, 감가상각누계액, 처분방법을 기재하여 위임전결 규정에 따라 반납 승인 — 단, **부외자산의 처분은 주관부서장의 전결**로 위임
- **처분** = 자산에 대한 소유권 또는 점유권을 상실하는 것 (**매각, 기증, 폐기, 기탁, 해체** 등)
- **반납자산의 해체**: 기술부서가 부품 활용을 위해 해체 시 '**부품적출 요청서**' 제출 → 주관부서 승인 후 해체 / 얻은 부품은 '**부품보유 현황 내역서**'로 **연 2회(반기별)** 보고 / 고장 수리에 사용하면 '**부품 사용 내역서**'를 **월 1회** 제출

**제20조(자산의 처분)** <a class="src" href="reader.html?doc=unit05&p=18">p.18</a><a class="src" href="reader.html?doc=unit05&p=10">p.10</a>

| 구분 | 기준 |
| :--- | :--- |
| **불용** 결정 | 사용할 수 없고 앞으로도 사용 전망이 없는 것 / 예측할 수 없는 일정기간의 수요를 초과하여 재고로 보유 / 원장비가 사용불능이거나 없어져 새로 취득할 가능성이 없는 부속품 / 수리해도 원래 목적에 사용할 수 없거나 수리가 비경제적 / 시설물에서 제거되어 활용할 수 없는 것 |
| **폐기** 결정 (불용 자산 중) | 매각되지 아니하거나 매각 전망이 없는 자산 / **매각비용이 매각대금을 초과**하는 자산 / 매각하는 것이 불리한 자산 / 법률에 의하여 사용·보유가 금지·제한된 자산 / 변질, 부패 등으로 매각할 수 없는 자산 — **단, 잔존물로서 매각의 가치가 있는 것은 폐기할 수 없음** |
| **매각** 결정 | 불용결정 자산 중 매각 처분하기로 결정된 자산 — **일반공개 입찰, 단가계약에 의한 매각, 수의계약** 등(구입 및 계약 사무규정) / 매각대금은 자산매각내역을 작성하여 **재무회계부서**로 통보 |

**제21조(반출제한)** — 의료원의 자산은 어떠한 경우를 막론하고 **원외로 반출할 수 없음** <a class="src" href="reader.html?doc=unit05&p=19">p.19</a>

| 반출 목적 | 서류 · 승인 |
| :--- | :--- |
| 차용, 대여 등으로 부득이한 반출 | '**자산반출승인 신청서**' 1부 작성 → **주관부서**의 승인 |
| **의료기기의 수리** 목적 반출 | 해당 **기술부서**에서 '**반출 및 입고 확인서**' 작성 → 승인 후 반출 |

- **제22조(자산의 재활용)** 불용·폐기결정 자산을 필요로 하는 부서가 있으면 예산절감 차원에서 재활용 **적극 권장** / 기술부서 의견상 사용가능 자산은 동일품목 청구 시 **우선불출** 고려 / 폐기결정 자산도 부속품 또는 전부를 요구하는 부서가 있으면 재활용 (그룹웨어 게시판: 기관별게시판/사무처/구매팀/**재활용창고**) <a class="src" href="reader.html?doc=unit05&p=11">p.11</a>

**제23조(자산의 손망실 처리)** <a class="src" href="reader.html?doc=unit05&p=19">p.19</a><a class="src" href="reader.html?doc=unit05&p=11">p.11</a>

| 용어 | 뜻 |
| :--- | :--- |
| 도난 | 도둑을 맞아 현물이 존재하지 않는 것 |
| 망실 | 잃어버려 없어져 현물이 존재하지 않는 것 |
| 훼손 | 고의/과실로 자산을 파손하여 효용가치가 상실되어 사용하지 못하게 된 것 |

| 구분 | 사용부서 | 주관부서(구매팀) |
| :--- | :--- | :--- |
| **유형자산** | '**자산손망실 신고서**' 작성 → **단위기관장 승인** 후 제출 | 손망실 경위 파악 및 처리방법을 위임전결 규정에 따라 승인 후 처리 (세부기준: '자산 손망실 처리 시행세칙') |
| **부외자산** | **부서장 승인** 후 신고 | 신고 접수 후 **기장에서 삭제** |

**자산 손망실 처리 시행세칙** <a class="src" href="reader.html?doc=unit05&p=12">p.12</a>

- **적용대상**: 고의 또는 중대한 과실로 훼손되어 사용불가 / 관리소홀로 도난·망실되어 자산이 없는 경우 / 자산 이동 후 주관부서에 **미통보**로 분실 / 자산 반납 절차 없이 **임의 폐기** / 반출 승인 없이 외부로 반출한 후 자산이 없는 경우 — **재산종합보험으로 보상받은 자산은 제외**
- **변상책임**: 손망실을 초래한 **원인 행위자, 관리책임자** / 원인행위자 2인 이상이면 각자의 책임한계에 따라, 불분명 시 **균등분할**
- **변상원칙**: 수리를 통한 **원상 회복** → 원상회복 불가 시 **현물보상** → 원상회복·현물변상 불가 시 **현금 변상** / 변상금 산정 시점: **원인 발생시점 또는 발견시점** / 시가 산정 불가 시: 취득금액 기준 **내용연수에 비례하여 감가상각**하여 변상 (단, **잔존가액 0원이면 변상 책임 면제**)
- **징계위원회 회부사안**: 손망실이 의료원 업무수행에 **특별한 지장**을 줄 경우 / **정당한 사유없이 변상절차 거부**

**부칙의 주요 개정 이력** <a class="src" href="reader.html?doc=unit05&p=19">p.19</a><a class="src" href="reader.html?doc=unit05&p=20">p.20</a>
